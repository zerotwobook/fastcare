# Fastcare — ภาพมือถือเวอร์ชันล่าสุด

แคปจากเว็บที่รันใน Docker เมื่อ 16 November 2026 หลังปรับ UI มือถือและเปลี่ยน More เป็น Care

- ภาพ 01–31 เป็น PNG ความละเอียด 1170 × 2532 พิกเซล (viewport 390 × 844, ความละเอียด 3 เท่า)
- 00-overview.png เป็นภาพรวมสำหรับเลือกไฟล์
- ลาก PNG เข้า Canva ได้โดยตรง คงสัดส่วนภาพหรือใช้ Fit เพื่อไม่ให้ครอป
- บางภาพเลื่อนถึงส่วนฟีเจอร์หลักเพื่อให้เห็นการใช้งานชัดเจน
- ใช้ข้อมูลตัวอย่างและเวลาโทรจำลองคงที่ ไม่ได้ยืนยันจอง ซื้อแผน หรือส่งคำขอจริง
- เป็นภาพจากเบราว์เซอร์จำลองขนาดมือถือ ไม่ใช่ภาพจากโทรศัพท์จริง
